# OpenTask no repositório PRISMA Intent

Este diretório guarda os registros metodológicos do PRISMA Intent. A fonte oficial das regras para agentes é `.opentask/diretrizes-agentes.md` no repositório `sidartaveloso/opentask`; este repositório não a copia para não divergir, e `AGENTS.md` resume o que é obrigatório aqui. Os modelos da metodologia (pacote, tarefa, critérios de aceite, revisão) também são os de lá.

## Modo de Inicialização

Os registros são Markdown + Git: pacotes em `pacotes/` (`AAAA-NNNNNN-slug/pacote.md`) e tarefas em `TASKS/` (taskin).

## Modelo de operação deste repositório

Os pacotes nascem com `modo: agencia` e `visibilidade: interna`: o PRISMA Intent é proprietário e closed-source.
