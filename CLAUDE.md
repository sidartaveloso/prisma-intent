# Instruções para Claude Code

Este projeto utiliza a metodologia OpenTask. Leia `AGENTS.md`, o pacote em `.opentask/pacotes/` e a tarefa em `TASKS/` relacionados à demanda antes de modificar o repositório.

Não implemente uma demanda sem pacote, tarefa e critérios de aceite registrados.

Não declare revisão, aceite, assinatura, liquidação ou pagamento sem evidência real.
